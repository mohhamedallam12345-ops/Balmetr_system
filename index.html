🛎️ 1. دخول الريسبشن

خطوات متسلسلة سريعة، منع تكرار العميل، إصدار كود تلقائي لغير المدعوين، وكارت العميل باللمس.

💼 2. دخول سيلز القعدة

حفظ تلقائي للجلسة ضد غلق المتصفح، عرض آراء من سبقك، وتسجيل قرارك ورأيك إجبارياً.

🔒

📥 مركز تحميل شيتات الإكسيل الموحد (اختر نوع الشيت ونطاق التصدير)
📵 1. شيت اللي محضروش المعرض (الغائبين) 0
يخرج كشف العملاء الذين صدرت لهم دعوات ولم يسجلوا دخول بالريسبشن نهائياً (الأكواد + الأسماء + التليفونات + السيلز) للرن عليهم.
✅ 2. شيت الحاضرين وتفاصيل القعدات والكومشن 0
يخرج كل العملاء الذين حضروا بالريسبشن، تقسيمة النص الأول (50%)، كارت اهتمامات العميل، والنص الثاني (50% القعدات وآراء السيلز).
📋 3. شيت شامل كل الدعوات (حضر / لم يحضر) 0
يخرج جميع الدعوات المصدرة للمعرض وموضح أمام كل عميل حالته: (✅ حضر المعرض + وقت حضوره) أو (❌ لم يحضر).
📈 4. شيت ملخص أرقام وإنجاز السيلز 0
يخرج جدول مجمع لكل السيلز: عدد الدعوات، كم عميل حضر منها، كم عميل غاب، عدد عملاء النص الأول، عدد القعدات، والمبيعات.
📊 جدول إنجاز السيلز الشامل (الدعوات + الحضور + الغياب + القعدات + شيتات فردية)
الكود اسم السيلز حالته في القعدة الدعوات المصدرة ✅ حضر من دعواته 📵 لم يحضروا (غائبين) حضر له (نص أول 50%) قعد معهم (نص ثاني 50%) 🟢 قاعد حالياً 💰 اشترى / حجز 🔥 مهتم / متابعة تحميل شيت السيلز الفردي
